\section{The Original Paper}
% =============================================================================

This replication targets \citet{luo2017l2boosting}, ``L2-Boosting for Economic
Applications,'' published in the \textit{American Economic Review: Papers \&
Proceedings} (2017, 107(5): 270--273). The paper asks whether L2-Boosting can serve as a competitive alternative to
Lasso for causal inference in high-dimensional settings, where the number of
potential covariates or instruments is large relative to the number of
observations.

The empirical strategy builds on the orthogonal moment conditions framework
of \citet{chernozhukov2016double}. Valid post-selection inference requires
that the variable selection step achieve a sufficient rate of convergence.
Luo and Spindler demonstrate, building on \citet{luo2016highdim}, that
post-L2-Boosting and orthogonal L2-Boosting satisfy these theoretical
conditions and achieve the same convergence rate as Lasso. They illustrate
the methods through two applications: IV estimation with many instruments
using the EminentDomain dataset, and inference on a treatment effect with
many controls using macroeconomic growth data.

\section{The Result of Interest}
% =============================================================================

This replication targets \textbf{Table 2} from the original paper, which
reports the estimated effect of federal appellate court property rights
decisions on log GDP per capita across four estimators. Specifically, the
paper reports:

\begin{center}
\begin{tabular}{lcccc}
\hline
 & post-Lasso & BA & post-BA & oBA \\
\hline
$\hat{\beta}$ & 0.005 & 0.005 & 0.004 & 0.008 \\
s.e.          & 0.012 & 0.007 & 0.006 & 0.006 \\
\hline
\end{tabular}
\end{center}

Table 2 is a natural replication target because it is the main empirical
result of the paper directly answering the research question
of whether L2-Boosting produces economically sensible estimates in a
real high-dimensional IV setting. It is also the most self-contained result,
depending only on the publicly available \texttt{EminentDomain} dataset from
the \texttt{hdm} package, with no simulation infrastructure required.

\section{Data and Methods}
% =============================================================================

\subsection*{Data}

Table 2 uses the \texttt{EminentDomain} dataset from the \texttt{hdm} R
package \citep{hdm2016}, originally constructed by \citet{belloni2012sparse}. The dataset contains
$n = 312$ observations with $p = 140$ potential instrumental variables
capturing federal appellate court judge characteristics and court composition.
The outcome is log GDP per capita (mean $= 11.2297$, s.d.\ $= 0.694$).
The treatment variable measures the share of pro-plaintiff appellate court
decisions, serving as an index of property rights protection strength.

\subsection*{What \texttt{preprocess.R} Does}

The preprocessing script loads \texttt{EminentDomain} directly from the
\texttt{hdm} package. It extracts the outcome (\texttt{y}), treatment
(\texttt{d}), instruments (\texttt{z}), and controls (\texttt{x}), dropping
column 50 of the control matrix following the original replication code.
All variables are then standardized: the outcome is demeaned only, while
the treatment, instruments, and controls are demeaned and scaled to unit
variance. The processed dataset is saved to \texttt{temp/eminent\_domain.rds}.
The script prints a console summary confirming $n = 312$, $p = 140$, and the
mean and standard deviation of log GDP.

\subsection*{What \texttt{analysis.R} Does}

The analysis script reads \texttt{temp/eminent\_domain.rds} and estimates
Table 2 using four estimators: post-Lasso IV (\texttt{rlassoIV} from
\texttt{hdm}), classical L2-Boosting IV (\texttt{boostSelectZ},
\texttt{post = FALSE}), post-L2-Boosting IV (\texttt{boostSelectZ},
\texttt{post = TRUE}), and orthogonal L2-Boosting IV
(\texttt{orthoboostSelectZ}), the latter three from the \texttt{newboost}
package. The table is written as a \LaTeX\ fragment to
\texttt{output/tables/table2.tex}. The script prints a console
summary comparing replicated values to the paper's targets.

\section{Replication Results}
% =============================================================================

%\input{../output/tables/table2.tex}

All four estimators produce small, positive point estimates of the effect of
property rights protection on log GDP per capita. The
boosting-based estimators (BA, post-BA, oBA) replicate the post-Lasso sign
and approximate magnitude, with modestly smaller standard errors in some
specifications. The economic
conclusion is unchanged for all four estimators.

Compared to the original paper, the replicated estimates across all methods match exactly when rounded to
three decimal places.

\section{What I Learned}
% =============================================================================

The easiest part of the replication was obtaining the data. The
\texttt{EminentDomain} dataset is bundled directly in the \texttt{hdm}
package, requiring no download step, no data cleaning decisions, and no
ambiguity about which version of the data was used. The original authors'
decision to distribute the data through a CRAN package made data extremely accessible.

The hardest part was dealing with the \texttt{newboost} package dependency. The package
is not available on CRAN and must be installed from R-Forge or requested
directly from the authors. R-Forge availability is intermittent and no version
number or changelog is documented. I also encountered a bug in the
\texttt{DGP()} function definition that causes a silent failure unless a
specific global variable happens to exist in the environment. This issue was self-induced after the accidental addition of a variable in the function when running the code separately, though this emphasizes how useful Makefiles can be in replication.

A broader lesson is the value of pipeline infrastructure. The original
replication package contains no Makefile, no enforced directory structure,
and no README beyond a brief file description. Reproducing the paper required
manually tracing dependencies across three R scripts with no automation.
Building this replication with a Gentzkow--Shapiro directory structure and
a Makefile made the dependency graph explicit and would allow any reader to
reproduce the result with a single \texttt{make} command. If the original
authors had provided even a minimal \texttt{run\_all.sh}, the replication
effort would have been substantially reduced.
